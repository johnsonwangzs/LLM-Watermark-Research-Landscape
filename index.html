ACL 2025
logits-based

论文 Duwak Dual Watermarks in Large Language Models
ACL 2024 Findings | Duwak
logits-based sampling-based
提出一种双水印（dual watermark）机制，在同一段 LLM 生成文本中同时嵌入两类独立信号：第一类沿用 KGW 风格，根据密钥和上下文将词表划分为 green/red list，并对 green token 的 logits 加偏置，从而形成可通过 green-token 统计检测的概率分布水印；第二类则用另一把密钥决定哪些位置采用 Contrastive Search、哪些位置采用普通 multinomial sampling，使被选中的位置倾向于生成与前文 hidden-state 相似度更低的 token，从而形成基于 self-similarity 差异的采样水印，同时改善文本多样性与质量。检测时分别对两种水印计算 p-value，再用 Fisher’s method 融合为最终检测结果。其核心思想是利用两种异质水印信号共同累积统计证据，以减少可靠检测所需的 token 数，并增强对 paraphrase 等 post-editing 攻击的鲁棒性。

论文 A Resilient and Accessible Distribution-Preserving Watermark for Large Language Models
ICML 2024 | DiPMark
distortion-free
本文提出 DiPmark，一种兼顾分布保持、可访问检测和修改鲁棒性的大语言模型生成时水印。其核心是在每个生成步根据秘密密钥和上下文生成一个随机词表排列，并对原始 next-token 概率做特殊的 DiP-reweight：将排列前部的一部分累计概率质量削弱甚至置零，同时增强后部 token 的概率，从而形成可由密钥恢复的 green-token 偏好；虽然对某个固定 permutation 而言单步分布会被明显改变，但作者证明对随机 cipher/permutation 求期望后可严格恢复原模型分布，因此称为 distribution-preserving。检测阶段无需模型或 prompt，只需密钥重新构造各位置的 green list，统计 green token 比例，并利用二项分布的 concentration bound 控制 FPR；同时论文还证明了在一定比例 token 修改下的 certified robustness。总体上，DiPmark 属于一种 distribution-preserving probability-reweighting watermark，与 KGW 的 green-list 思路接近，但其重点是在不改变边缘生成分布的前提下保留可检测的密钥相关偏置。

Workshop | Aar/EXP
sampling-based distortion-free
一种基于 Gumbel/指数竞争采样的水印，每步生成时基于密钥和上下文为每个 token 产生随机值，最终选择同时具有高原始概率 和高伪随机值 的 token。

论文 Robust Distortion-free Watermarks for Language Models
TMLR 2024 | KTH/EXP-Edit/ITS-Edit
sampling-based distortion-free
将 Aar 的 Gumbel/exponential sampling 中原本由文本上下文 hash 产生的伪随机数，替换成一条独立的秘密随机 key sequence，在每次插入水印时随机选择该序列中的起始位置以引入随机性，使水印文本在对随机 key 边缘化后严格保持原 LM 分布。两种水印方案分别为逆变换采样（inverse tranforme sampling）和指数最小采样（exponential minimum sampling）。此外，在水印检测过程中，他们将一种软性的编辑距离（即 Levenshtein 距离）引入文本与伪随机数序列的对齐计算中。这种方法显著增强了水印算法对抗水印移除攻击的鲁棒性。

论文 An End-to-End Model For Logits Based Large Language Models Watermarking
ICML 2025
logits-based neural
本文提出了一种端到端训练的 logits-based LLM 水印方法：在生成每个 token 时，水印 Encoder 根据当前上下文和原模型 top-k 候选 token 动态输出一组 logit perturbation，再加到原始 logits 上以嵌入水印；训练时用 Gumbel-Softmax 将离散采样过程连续化，使检测损失能够反向传播到 Encoder，同时利用同一个冻结 LLM 通过 online prompting 对水印文本进行 paraphrasing，并提取语义表示，从而联合优化检测鲁棒性和文本语义质量。检测端则使用一个 LSTM+MLP 的神经 Decoder 判断文本是否含水印。其核心区别于 KGW/SIR 等方法在于：水印 Encoder、攻击模拟和 Detector 被放进同一个可微训练闭环中联合优化，因此能直接学习对改写攻击更鲁棒、同时较少损伤文本质量的 logit 偏置模式。

论文 Context-aware Watermark with Semantic Balanced Green-red Lists for Large Language Models
EMNLP 2024
logits-based
用前一个 token 的 embedding 经过 LSH 生成语义相关的 watermark key，使语义相近的上下文更可能得到相同 key，从而提升 paraphrasing 后检测阶段与嵌入阶段的对齐稳定性；随后先将词表按语义划分成多个集合，再在每个语义集合内部按比例随机划分 green/red tokens，使 green list 能覆盖各个语义区域，减少传统随机 green list 对生成语义的限制；最后根据当前 next-token 分布的 entropy 动态调整 green-token bias，在保证水印强度的同时尽量降低对原始生成分布的扰动。检测阶段则依据文本上下文重建每个位置的 green/red list，统计 green token 数量并通过 z-score 判断是否含有水印。

论文 A Robust Semantics-based Watermark for Large Language Model against Paraphrasing
NAACL 2024 Findings | SemaMark
logits-based
对前 个 token 的 hidden embeddings 做加权池化，再通过训练好的 MLP 映射到二维 NE-Ring，将连续语义离散成少量稳定的 semantic values，并以此作为 seed 生成 green list，随后提升 green-token 的 logits 完成水印嵌入。

论文 A Semantic Invariant Robust Watermark for Large Language Models
ICLR 2024 | SIR
logits-based neural

论文 X-SIR Can Watermarks Survive Translation On the Cross-lingual Consistency of Text Watermark for Large Language Models
ACL 2024 | X-SIR
logits-based neural
本文研究 LLM 文本水印的跨语言一致性，即带水印文本经过翻译后水印是否仍能保留。作者发现 KGW、UW、SIR 等现有 generation-time 水印在翻译后水印强度会显著下降，因此提出 CWRA（Cross-lingual Watermark Removal Attack）：先把原始 prompt 翻译成一个 pivot language，让带水印的 LLM 在该语言中生成，再把生成结果翻译回目标语言，从而显著削弱甚至接近移除水印。进一步地，作者指出跨语言鲁棒性需要同时满足两点：语义等价的跨语言 token 应具有相同的 green/red 属性，语义等价的跨语言上下文也应产生相似的 vocabulary partition。据此提出 X-SIR，它在 SIR 的 learned semantic logits-bias 框架上，将原本的 token-level bias 改为基于多语言词典构建的 semantic-cluster-level bias，使互为翻译或语义相近的 token 共享相同水印偏置，从而显著提高翻译和 CWRA 场景下的检测鲁棒性。

论文 SoK Watermarking for AI-Generated Content
IEEE S&P 2025
本文是一篇系统梳理生成式 AI 内容水印的 SoK，重点不是提出新的水印算法，而是建立统一的分析框架：作者从质量保持、低误报、可检测性/鲁棒性、不可伪造性、多比特信息容量和计算效率等维度定义“好的水印”，并系统区分 watermark removal、forgery、secret extraction 等攻击目标及不同攻击者能力；随后总结检测效果、攻击鲁棒性和内容质量的标准评测方法，并以文本水印中的 Green-Red/KGW、Gumbel、Undetectable Watermark、Pseudorandom Error-Correcting Codes、SemStamp/k-SemStamp 以及图像水印中的 Stable Signature、Tree-Ring、Gaussian Shading、PRC 等代表工作说明不同技术路线的权衡。论文的核心观点是：水印研究不应只关注检测准确率，而应同时考虑分布失真、鲁棒性、低 FPR、不可伪造性与实际部署效率之间的 trade-off，其中强鲁棒的公开验证、document-level semantic watermark、proof-of-generation 和开放模型水印仍是重要开放问题。

论文 Position LLM Watermarking Should Align Stakeholders Incentives for Practical Adoption
ACL 2026 Findings
本文是一篇讨论 LLM 水印实际落地问题的立场论文，核心观点是：水印能否被广泛采用，关键不只在于检测准确率、鲁棒性和文本质量，还取决于不同利益相关者的 激励是否一致。作者指出，传统 LLM 文本水印用于统一标记 AI 内容时，模型提供商可能面临用户流失、检测密钥治理和归因不清等问题，因此部署动力有限；相比之下，模型水印可直接保护开发者 IP，激励更自然一致，而文本水印若用于过滤自身生成数据、保护用户机密内容等场景，也能产生直接价值。论文重点提出并倡导 In-Context Watermarking（ICW）：由会议组织者、教师等可信第三方在输入文档中隐藏水印指令，使违规将文档提交给 LLM 时，模型生成的文本带上可检测信号，从而无需修改模型或解码过程即可追踪特定场景中的 LLM 滥用。总体上，论文主张未来水印应从“追求通用技术性能”转向“面向具体应用场景、明确威胁模型并对齐各方激励”的设计思路。

论文 WaterBench Towards Holistic Evaluation of Watermarks for Large Language Models
ACL 2024 | WaterBench
本文提出 WaterBench，一个面向大语言模型文本水印的综合评测框架，核心目标是更公平地衡量水印的检测能力与生成质量之间的权衡。其关键做法是先通过超参数搜索，把不同水印方法调整到相同的 watermarking strength（以 TPR 表示，如 0.95），再联合比较检测性能和生成质量；同时构建了覆盖 5 类输入/输出长度组合、共 9 个 NLP 任务的多任务基准，并在开放式生成任务中引入 GPT4-Judge 评估 instruction-following 质量。实验比较了 Hard、Soft、GPT 和 V2 等水印，发现高检测强度往往会显著损害生成质量，尤其开放式任务下降最严重，而短输出又会明显削弱检测能力；因此本文的主要贡献不在于提出新水印，而在于强调并系统评估 quality–detection trade-off。

论文 WaterJudge Quality-Detection Trade-off when Watermarking Large Language Models
NAACL 2024 Findings | WaterJudge
本文提出 WaterJudge，一个用于分析 LLM 文本水印中“文本质量—检测性能”权衡关系的评估框架。论文并未提出新的水印算法，而是以 KGW 式 green-list soft watermark 为例，通过改变 green-list 比例 和 logit bias 得到不同强度的水印设置；对每组设置，一方面用 衡量水印检测性能，另一方面使用 FLAN-T5 进行 pairwise LLM-as-a-Judge 比较，计算水印文本相对于无水印文本被偏好的概率作为质量指标，从而绘制 quality–detectability trade-off 曲线并选择合适的 operating point。实验在 BART、Zephyr 和 mBART 的摘要与翻译任务上表明：水印越强通常检测越容易，但文本质量下降越明显；较强的生成模型对水印扰动更耐受；同时该比较式质量指标与 UniEval、COMET 高度相关，比 PPL、ROUGE、BLEU 更能反映水印造成的真实质量退化。此外，不同模型和任务上的 trade-off 具有较强相关性，说明水印参数可能具有一定的跨模型迁移和预测能力。

论文 PVMark Enabling Public Verifiability for LLM Watermarking Schemes
USENIX 2026 | PVMark
public-verifiable
本文提出 PVMark，一种基于零知识证明（ZKP）的大模型水印公开验证框架，旨在解决传统私钥水印无法向第三方可信地证明检测结果，而公开密钥又容易导致水印被移除或伪造的问题。其核心方法是：将现有水印的嵌入和检测算法改造为 ZKP 友好的形式，并在检测端引入零知识证明，使第三方无需获取水印密钥即可验证检测计算的正确性。 具体而言，作者使用 MiMC、Poseidon 等密码学哈希函数替代原有伪随机计算，将水印检测过程转换为哈希、比较、累加等可证明的算术约束，并通过 Nova 递归证明降低长文本的证明开销。实验将 PVMark 应用于 KGW、SynthID-Text 和多比特 Segment-Watermark，表明其总体上能够保持原有水印的检测性能、文本质量和鲁棒性，同时实现较高效的公开验证。需要注意，PVMark 实现的是检测结果的公开可验证性，而非第三方无需密钥即可独立执行的公开检测。

论文 A watermark for large language models
